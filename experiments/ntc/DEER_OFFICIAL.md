# DEER: results of the authors' code

Recorded input, not generated by this repository. DEER was run from its authors'
code (github.com/iie-ycx/DEER, vendored under `external/DEER`) at its default
configuration: confidence threshold 0.95, think ratio 0.8, policy avg2, at most
16,000 tokens, greedy decoding, on the same models and items as the matched
comparison, and scored with the same grader. `final_tokens` is the length of the
chain DEER keeps; `total_tokens_incl_trials` adds every trial answer DEER pays
online, which is the count compared in `H2H_TABLE.md`. Read by
`scripts/ntc_h2h_table.py` and `scripts/ntc_ckpt_density.py`.
